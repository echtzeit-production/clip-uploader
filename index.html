Clip Uploader

Clip Uploader is a personal desktop tool. It sends short video clips that the operator edited himself to his own TikTok account as drafts (TikTok inbox), using the official TikTok Content Posting API. The operator then reviews, edits and publishes each draft manually in the TikTok app.

The tool is not offered to the public and is used only with the operator's own TikTok account.
